## 1.1.1
- Added spawn elevation slider (0m - 300m, step 10m) to elevate terrain near world origin and prevent water submergence.
- Added Nether terrain style option in customization screen and config: Overworld-like (gentle rolling hills with bedrock ceiling preserved) vs Vanilla cave maze.
- Optimized chunk generation around world origin to eliminate multi-lock thread pauses.
- Streamlined multiloader support to Fabric and NeoForge.

## 1.1.0
- Added The Nether dimension spiral support with independent dimension toggles.
- Added in-game customization screen with real-time 2D map preview (accessible via the Customize button).
- Added configurable spiral styles (Standard, Large, Dense, Tight, Custom), scale, and growth rate sliders.
- Added customizable boundary divider blocks with searchable block picker and adjustable wall height (flat paving or 1-5 blocks tall).
- Added seamless compatibility with major biome mods (Terralith, Incendium, Biomes O' Plenty, Promenade, TerraBlender, etc.).
- Fixed dimension preset overrides by datapack mods like Incendium.

## 1.1.0
- Added The Nether dimension spiral support with independent dimension toggles.
- Added in-game customization screen with real-time 2D map preview (accessible via the Customize button).
- Added configurable spiral styles (Standard, Golden Ratio, Tight, Loose, Custom), scale, and growth rate sliders.
- Added customizable boundary divider blocks with searchable block picker and adjustable wall height (flat paving or 1-5 blocks tall).
- Added seamless compatibility with major biome mods (Terralith, Incendium, Biomes O' Plenty, Promenade, TerraBlender, etc.).
- Fixed dimension preset overrides by datapack mods like Incendium.

# Logarithmic Spiral Biome
![](common/src/main/resources/logarithmicspiralbiome.png)
Minecraft Forge/Fabric/NeoForge 1.20.1/1.20.4/1.20.6/1.21.1/1.21.4/1.21.11/26.1/26.3 mod that generates Overworld and Nether biomes in a logarithmic spiral pattern.

## Features

- Adds a `Logarithmic Spiral` world preset.
- Supports both the Overworld and the Nether dimensions.
- In-game customization screen with live map preview (accessible via the Customize button).
- Configurable spiral styles (Standard, Golden Ratio, Tight, Loose, Custom), scale, and growth rate.
- Customizable boundary divider blocks and wall height (flat paving or 1–5 block walls).
- Compatible with major biome and world generation mods (Terralith, Incendium, Biomes O' Plenty, Promenade, TerraBlender, etc.).
